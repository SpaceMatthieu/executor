---
title: Secret-sink signals (allowlist + forbidden fields)
description: Signals that orchestrate box-side secret-sink joins must never contain key material. This page documents the JSON allowlist and the forbidden secret-shaped fields.
---

### What counts as a "signal"

Signals are GitHub-visible JSON envelopes that instruct a box-side secret-sink to perform a limited action. They are not credentials and must never include key material.

- Allowed action (strict): `tailscale.join`
- Allowed fields (payload): `action`, `hostname`, `tags[]`, `dryRun`, optional `authKeyFrom` metadata
- Allowed fields (server-added job metadata): `jobId`, `status` (queued | running | done)
- Forbidden in both payload and metadata: any `tskey-*`, Bearer tokens, API keys, 1Password item values, or secret-shaped fields

### Allowlisted payload shape

```json
{
  "action": "tailscale.join",
  "hostname": "dynamik-ops-grokbot",
  "tags": ["tag:grok-ops"],
  "dryRun": true,
  "authKeyFrom": {
    "connection": "tailscale_api.user.dynamikTailscale",
    "op": "keys.createKey",
    "params": { "capabilities": { "devices": { "create": { "tags": ["tag:grok-ops"] } } } }
  }
}
```

### Forbidden (rejected)

- Secret-shaped field names anywhere: `authKey`, `secret`, `secretKey`, `token`, `bearer`, `password`, `credential`, `tskey`
- Secret-shaped values anywhere:
  - Tailscale auth key: `tskey-…`
  - HTTP Authorization: `Bearer …`
  - 1Password URIs: `op://…`

Rejections are enforced by schema validation and a recursive secret-shaped scan. Violations return a tool failure:

```json
{ "ok": false, "error": { "code": "forbidden_secret_field", "message": "Secret-shaped fields/values are forbidden in secret-sink signals; never include authKey, tskey-*, bearer tokens, or raw credentials in GitHub-visible signals." } }
```

### Outputs never include secrets

`executor.secretSink.runOnBox` responds with:

```json
{ "joined": false, "hostname": "dynamik-ops-grokbot", "dryRun": true }
```

No `tskey-*`, no bearer, no raw credential fields — ever.

Note: Runtime delivery is handled by the SpaceMatthieu/agent-access tenant overlay (box-secret-sink), not by this sketch alone.
